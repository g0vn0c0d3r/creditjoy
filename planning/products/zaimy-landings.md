# Лендинги продукта: займы

Статус: рабочий выбор типов лендингов для дальнейшей разработки.

Дата: 2026-08-02.

## Зачем документ

Мы уже собрали схему продукта `займы`: продукт, интенты, города и комбинации `интент + город`.

Теперь фиксируем, какие типы лендингов нужно проектировать. Это еще не текстовая структура страниц, не шаблоны и не финальный реестр URL.

Связанные файлы:

- `planning/products/zaimy-structure.md` - схема продукта, URL и масштабирование.
- `ROADMAP.md` - верхний план, стратегия и конкуренты.
- `data/competitor-loan-slugs.csv` - полный рыночный список найденных слагов.
- `data/keywords.csv` - семантика для привязки к выбранным лендингам.

## Основа

Рыночная модель у конкурентов простая:

```text
продукт -> интент -> город -> компания/оффер -> блог/справка
```

Для CreditJoy не придумываем новую вложенность. Берем эту модель и дальше улучшаем полезность страниц.

## Типы лендингов

```text
/ - главная проекта
|
|-- /zaimy/ - продуктовая витрина
|   |
|   |-- /zaimy/{intent}/ - витрина интента
|   |   `-- /zaimy/{intent}/{city}/ - интент в городе
|   |
|   `-- /zaimy/{city}/ - займы в городе
|
|-- /companies/{slug}/ - карточка компании
|-- /blog/{slug}/ - блог или справка
`-- /calculators/{slug}/ - калькулятор или сервис
```

Коротко по ролям:

| Тип | URL | Зачем нужен |
| --- | --- | --- |
| Главная проекта | `/` | Вход в CreditJoy и будущие продукты |
| Продуктовая витрина | `/zaimy/` | Главный хаб займов |
| Витрина интента | `/zaimy/{intent}/` | Отдельный сценарий выбора займа |
| Займы в городе | `/zaimy/{city}/` | Все займы для конкретного города |
| Интент в городе | `/zaimy/{intent}/{city}/` | Сценарий выбора займа в конкретном городе |
| Карточка компании | `/companies/{slug}/` | Доверие, условия, отзывы и связь с витринами |
| Блог/справка | `/blog/{slug}/` | Информационная поддержка коммерческих страниц |
| Калькулятор/сервис | `/calculators/{slug}/` | Интерактивная польза и вход в подбор |

## Что проектируем первым

Для раздела `займы` сначала нужны коммерческие типы:

1. `/zaimy/` - продуктовая витрина.
2. `/zaimy/{intent}/` - витрина интента.
3. `/zaimy/{city}/` - займы в городе.
4. `/zaimy/{intent}/{city}/` - интент в городе.
5. `/companies/{slug}/` - карточка компании.

Отдельно после коммерческого ядра:

1. `/` - главная проекта, когда станет понятно, как займы соседствуют с будущими продуктами.
2. `/blog/{slug}/` - блог и справка.
3. `/calculators/{slug}/` - калькуляторы и сервисы.

## Как выбирать конкретные лендинги

Сначала выбираем не все 301 рыночный слаг, а стартовый набор:

1. продуктовый хаб: `/zaimy/`;
2. несколько сильных интентов из `data/competitor-loan-slugs.csv`;
3. первые города;
4. комбинации `интент + город` только для выбранных интентов и городов.

Пример логики:

```text
выбрали 5 интентов и 5 городов
=
1 продуктовая
+ 5 интентных
+ 5 городских
+ 25 страниц интент + город
= 36 страниц без главной
```

## Что не решаем здесь

В этом файле не описываем:

- полный контент каждой страницы;
- тексты, FAQ и заголовки;
- все MVP-слаги;
- финальный реестр страниц;
- правила для каждого отдельного интента.

Это следующий этап после выбора конкретных лендингов.
