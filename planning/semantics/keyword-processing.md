# Обработка слов

Цель обработки - получить один общий рабочий файл запросов без преждевременной кластеризации.

## Источники

Скрипт читает 3 Wordcraft-файла:

- `data/raw/wordcraft/wordcraft-zaim.xlsx`
- `data/raw/wordcraft/wordcraft-microzaim.xlsx`
- `data/raw/wordcraft/wordcraft-microcredit.xlsx`

В каждом файле используются только листы:

- `Queries`
- `AdditionalQueries`

Колонка `cluster` из Wordcraft игнорируется.

## Правила

1. Все запросы приводятся к нормальной форме для дедубликации.
2. Одинаковые запросы из разных файлов объединяются в одну строку.
3. Для `clicks` и `demand` берется максимум, а не сумма.
4. Запросы сортируются по `clicks`, затем по `demand`.
5. Никакие бакеты, страницы и кластеры автоматически не назначаются.

## Результат

Главный файл:

- `data/keywords.csv`

Поля:

- `query` - текст запроса.
- `clicks` - максимальное значение кликов по дублям.
- `demand` - максимальное значение спроса по дублям.
- `sources` - исходные Wordcraft-файлы, где найден запрос.
- `decision` - поле для ручного решения.
- `notes` - поле для ручных заметок.

Если `decision` и `notes` уже заполнены, скрипт сохраняет их при пересборке по совпадению запроса.

## Пересборка

```bash
node scripts/build-keywords.mjs
```

В этой среде удобнее запускать через встроенный Node.js Codex, но сам скрипт остается обычным Node.js-файлом.
