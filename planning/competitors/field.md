# Конкурентное поле по займам

Статус: первичный срез для продукта `займы`.

Дата среза: 2026-07-31.

## Как собираем

- Смотрим коммерческие запросы: займы онлайн, займ на карту, без процентов, с плохой КИ, под залог ПТС, под залог недвижимости, займы в городах.
- Делим игроков по роли, а не только по месту в выдаче.
- В глубокий разбор берем тех, у кого есть сильная структура, данные, доверие или масштабируемая SEO-сетка.
- Нишевых игроков используем как референсы для отдельных интентов.

## Топ для глубокого разбора

1. `Sravni.ru` - продуктовый UX, хаб, интенты, гео, заявка.
2. `Bankiros.ru` - широкая SEO-матрица, длинный хвост, гео, поздний рост через структуру.
3. `Banki.ru` - доверие, отзывы, рейтинги, карточки компаний.
4. `Finuslugi.ru` - юридическая чистота, безопасность, официальный тон.
5. `Brobank.ru` - финансовая витрина, готовые решения, подробные условия и справочные блоки.

## Дополнительные SEO-референсы

6. `Zaym.me` - простые фильтр-страницы, таблицы, быстрые подборки.
7. `Zaim.com` - специализированный портал по МФО, каталог компаний, новости, отзывы.
8. `Zaime.ru` - простой подбор займов, партнерская витрина, способы получения.
9. `Rus.credit` - каталог МФО, условия, акцент на легальность.
10. `Microcreditor.ru` - длинный хвост по ПТС и микрозаймам.
11. `Creditulka.com` - агрессивная SEO-сетка по безотказным и похожим интентам.
12. `Zabiray.ru` - новый маркетплейс с упором на понятные условия и блог.
13. `Zaim-tebe.ru` - простая витрина срочных займов и длинный хвост.
14. `Zaimi.tv` - агрессивная выдачная витрина под онлайн/без отказа.
15. `RBZaym.ru` - интентные страницы под высокий шанс одобрения.

## Нишевые референсы по залогу

16. `PTS-Zaim.com` - ПТС/авто как отдельная вертикаль.
17. `PodPTS.ru` - подбор ПТС-займов с компаниями, рейтингом и параметрами.
18. `CashPTS.ru` - лидген под ПТС/авто, калькулятор, быстрый CTA.
19. `CarZalog.ru` - залог авто/ПТС, оффер под крупные суммы.
20. `Carzaem.com` - продуктовый UX залогового займа, калькулятор, офисы, рефинансирование.

## Что это значит для CreditJoy

- Основу структуры берем у топ-5, не у нишевых сайтов.
- Нишевые сайты помогают понять отдельные коммерческие интенты: ПТС, авто, недвижимость, высокая вероятность одобрения.
- Агрессивные формулировки не копируем как обещания: `без отказа`, `100% одобрение`, `без проверок`.
- Для MVP берем только чистые коммерческие страницы с реальной пользой и офферами.
- Остальное фиксируем как `later` или используем для алиасов.
