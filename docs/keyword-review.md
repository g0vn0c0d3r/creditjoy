# Ручной разбор семантики

Дата старта ручного разбора: 2026-07-28.

Главный рабочий файл остается `data/keywords.csv`. На этом этапе не создаем финальные slug-кластеры, реестр страниц или старую структуру `processed/buckets/page-candidates`.

## Цель этапа

Разметить запросы по пригодности для будущих коммерческих страниц:

- что точно подходит под коммерческий листинг;
- что выглядит коммерческим, но требует отдельной проверки;
- что относится к брендам, личным кабинетам, навигационному спросу или мусору;
- что стоит отложить до появления офферов, данных и правил антидублей.

## Рабочие значения `decision`

Пока используем короткие рабочие метки, а не будущие страницы:

- `commercial` - запрос подходит под коммерческий листинг или коммерческий хаб.
- `maybe` - интент похож на коммерческий, но нужно проверить выдачу, офферы или риск дублей.
- `brand` - брендовая или навигационная семантика МФО/сервиса.
- `spam` - партнерский, телеграмный, дорвейный или явно искусственный хвост.
- `info` - информационный запрос без прямого коммерческого листинга.
- `later` - потенциально полезно позже, но не для первой ручной выборки.
- `exclude` - не подходит для проекта.

`notes` используем для короткой причины решения: например `core loans`, `card modifier`, `brand/lk`, `affiliate spam`, `needs serp check`.

## Что точно брать в первый коммерческий проход

Высокая уверенность:

- базовые интенты: `займ`, `займы`, `микрозайм`, `микрокредит`;
- получение онлайн;
- получение на карту;
- онлайн + на карту;
- без отказа;
- без процентов / первый займ без процентов;
- с плохой кредитной историей / с просрочками;
- срочно / быстро / моментально / мгновенно;
- до зарплаты;
- под залог ПТС / авто;
- по паспорту / без справок / без проверок;
- лучшие / топ / рейтинг / все займы, если интент именно сравнить предложения.

## Что сразу отделять

Не смешиваем с коммерческими листингами:

- бренды МФО и сервисов: `лайм займ`, `юкки`, `турбозайм`, `веб займ`, `квику`, `привет сосед`, `а деньги`, `бустра`, `корона`, `капуста`, `небус`, `доброзайм` и похожие;
- личные кабинеты, вход, ЛК, оплату, продление и возврат займа;
- `t_me_top_zaim24`, `вам одобрено` и похожие искусственные хвосты;
- запросы с неестественной формулировкой, если за ними нет понятного пользовательского сценария.

## Сомнительное для отдельного прохода

Проверять после точной коммерции:

- `новые займы`, `малоизвестные займы`;
- `займы через госуслуги`;
- `займы без карты`;
- `займ ооо`;
- суммы и сроки;
- аудитории: студенты, пенсионеры, безработные, 18 лет;
- гео-комбинации;
- формулировки с высоким риском дублей: несколько модификаторов в одном запросе.

## Порядок разметки

1. Разобрать первые 300-500 строк по кликам и проставить `commercial`, `maybe`, `brand`, `spam`, `info`, `later` или `exclude`.
2. Внутри `commercial` пока не назначать slug: только короткая причина в `notes`.
3. Отдельно проверить брендовые запросы: оставить ли их как будущий каталог МФО или исключить из первого MVP.
4. Отдельно проверить `maybe` через выдачу и конкурентов.
5. Только после ручной выборки собирать будущие группы страниц.
