# Правки

Здесь лежат задачи на изменение уже существующих экранов и админки продукта `займы`.

- `admin/` - функциональные правки админки; `tasks.md` описывает задачи, `assets/` хранит скриншоты.
- `design/<тип-лендинга>/` - визуальные правки конкретной публичной страницы; `tasks.md` описывает проблему и ожидаемое изменение, `assets/` хранит ориентиры.

Утвержденные макеты и дизайн-наброски сюда не складываем. Они принадлежат конкретному лендингу и хранятся в `landings/<тип-лендинга>/design/`.
