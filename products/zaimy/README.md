# Займы

Рабочий продукт CreditJoy. Сейчас фокус - вертикальный MVP: главная, `/zaimy/`, админка офферов и рабочая витрина.

## Навигация

- `roadmap.md` - порядок работ и выводы из исследования рынка.
- `structure.md` - утверждённая URL-структура, типы лендингов и логика витрин.
- `changes/README.md` - правила классификации задач по админке и дизайну.
- `research/competitors/` - найденные URL и слаги конкурентов.
- `landings/README.md` - правила для брифов, дизайн-набросков и утвержденных макетов.
- `landings/company/source-packs/` - правила и файлы для загрузки данных организаций в админку.
