# Source packs для МФО

Папка для исходных материалов по организациям МФО. Эти файлы нужны не как финальные карточки, а как сырье для окна админки «Заполнить карточку через AI».

## Цель

Собрать по каждой организации один `.md`-файл с контентом источников: официальный сайт, страницы условий, документы, FAQ, карточка ЦБ, ЕГРЮЛ/ФНС и агрегаторы. Если у организации есть несколько продуктовых карточек или офферов, собираем их отдельными блоками внутри того же файла. AI должен видеть, откуда взят каждый блок, какой у источника приоритет и где есть конфликты.

## Формат файла

В шапке файла:

```text
# Название организации: source pack

Дата сбора: YYYY-MM-DD

Официальный сайт: https://example.ru/
```

Дальше источники идут отдельными блоками:

```text
# Источник 1. Название источника / страницы

URL: https://...

Тип источника: официальный сайт / государственный источник / официальный PDF / агрегатор / вторичный источник

Приоритет: высокий / средний / низкий

Контент страницы:
...
```

Если источник содержит несколько офферов одной организации, каждый оффер фиксируем отдельно:

```text
## Оффер: Название оффера

Источник оффера: официальный сайт / официальный PDF / Банки.ру / Сравни / другой источник

URL:

Статус источника: актуальный / архивный / требует проверки

Контент карточки оффера:
- название;
- сумма;
- срок;
- срок без процентов;
- ставка;
- ПСК;
- требования;
- документы;
- способы получения;
- способы погашения;
- дата актуализации, если указана.
```

Не схлопываем несколько офферов в один общий займ. Например, если у одной МФО есть «Займ для новых клиентов», «Займ онлайн» и «Займ для постоянных клиентов», это три разных офферных блока.

## Приоритет источников

1. ЦБ РФ: статус, тип МФО, запись в реестре, дата включения, официальный сайт.
2. ФНС / ЕГРЮЛ: юридическое название, ИНН, ОГРН, КПП, адрес, статус юрлица.
3. Официальный сайт МФО: описание компании, контакты, способы получения и погашения, FAQ, пользовательские формулировки.
4. Официальные PDF МФО: суммы, сроки, ставки, ПСК, штрафы, правила займа, права клиента.
5. Агрегаторы и классификаторы: Банки.ру, Сравни и похожие источники использовать только для сверки и дополнительного контекста.

## Офферы

Одна организация может иметь несколько офферов с разными названиями и условиями. В source pack нужно собирать не только данные организации, но и найденные офферные карточки.

Правила:

- офферные карточки из агрегаторов считаются кандидатами на офферы, а не финальными условиями;
- официальный сайт и официальные PDF важнее агрегаторов;
- если продукт на агрегаторе помечен как архивный, неактуальный или «не предоставляется», это обязательно фиксируем;
- если у агрегатора несколько карточек одной МФО, собираем каждую карточку отдельно;
- если официальный сайт описывает один общий продукт, а агрегатор дробит его на несколько карточек, сохраняем оба вида источников без склейки;
- если условия оффера конфликтуют между источниками, конфликт фиксируем рядом с этим оффером.

## Конфликты

Если источники противоречат друг другу, конфликт нужно оставить в файле явно:

```text
Конфликт:
- Официальный сайт: возраст 19-70.
- Сравни: возраст 21-90.
Приоритет: официальный сайт / официальный PDF.
```

Не нужно молча смешивать данные из разных источников. AI и человек должны видеть, почему один источник надежнее другого.

## Что не делаем

- Не пишем финальную карточку от себя.
- Не делаем итоговую выжимку вместо источников.
- Не считаем агрегаторы источником истины для условий займа.
- Не используем архивные офферы как актуальные без явной пометки.

## Имена файлов

Используем короткие латинские slug-и:

```text
lime-zaim.md
webbankir.md
ykky.md
bystrodengi.md
```
