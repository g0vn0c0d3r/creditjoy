# Source packs для МФО

Это исходные материалы для окна админки «Заполнить карточку через AI». Они разделены на организацию и офферы: так модель не принимает описание МФО за название продукта.

## Структура

```text
source-packs/
  README.md
  organizations/
    lime-zaim.md
  offers/
    lime-zaim/
      zaim-besplatno.md
      zaim.md
```

- `organizations/<slug>.md` - только карточка организации: юридические данные, реестры, контакты, описание, контент и SEO.
- `offers/<organization-slug>/<offer-slug>.md` - один файл на один оффер; его можно отдельно передать AI для создания или обновления продукта.

В шапке каждого файла обязательно указываем официальный сайт организации.

## Формат источника

```text
# Источник. Название страницы

URL: https://...

Тип источника: официальный сайт / государственный источник / официальный PDF / агрегатор / вторичный источник

Приоритет: высокий / средний / низкий

Контент источника:
...
```

В офферном файле перед источниками всегда есть явное поле:

```text
Название оффера для админки: Займ бесплатно
```

AI берет имя продукта только из этого поля или точного заголовка продуктовой карточки источника. Название МФО, SEO-заголовки вроде «Онлайн-заем в МФК ...» и общий текст страницы не могут стать названием продукта.

## Приоритет источников

1. ЦБ РФ: статус, тип МФО, запись в реестре, дата включения, официальный сайт.
2. ФНС / ЕГРЮЛ: юридическое название, ИНН, ОГРН, КПП, адрес, статус юрлица.
3. Официальный сайт МФО: описание компании, контакты, способы получения и погашения, FAQ, пользовательские формулировки.
4. Официальные PDF МФО: суммы, сроки, ставки, ПСК, штрафы, правила займа, права клиента.
5. Агрегаторы и классификаторы: Банки.ру, Сравни и похожие источники использовать только для сверки и дополнительного контекста.

## Офферы

Оффер создаем отдельным файлом, когда есть отдельное название карточки и отдельные условия или отдельная продуктовая страница. Название МФО в название оффера не добавляем.

- Офферные карточки агрегаторов - кандидаты; официальные документы важнее для финальных условий.
- Если у агрегатора несколько карточек одной МФО, не склеиваем их автоматически.
- Имя, которое встречается только в обзорном тексте или блоке отзывов без своей карточки и условий, не становится отдельным продуктом.
- Источник с пометкой «не предоставляется» остается только как контекст с этим статусом; активный оффер по нему не создаем.
- Конфликты условий фиксируем в файле конкретного оффера.

## Конфликты

Если источники противоречат друг другу, конфликт нужно оставить в файле явно:

```text
Конфликт:
- Официальный сайт: возраст 19-70.
- Сравни: возраст 21-90.
Приоритет: официальный сайт / официальный PDF.
```

Не нужно молча смешивать данные из разных источников. AI и человек должны видеть, почему один источник надежнее другого.

## Что не делаем

- Не пишем финальную карточку от себя.
- Не смешиваем организационные данные с продуктовым импортом.
- Не считаем агрегаторы источником истины для условий займа.
- Не создаем продукт из устаревшей или неподтвержденной карточки.
