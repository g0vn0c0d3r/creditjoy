# Лендинг: `/zaimy/{intent}/{city}/`

Статус: позже.

Дата: 2026-08-05.

## Зачем файл

Здесь будем фиксировать структуру страницы интента в городе: например `/zaimy/na-kartu/moskva/`, `/zaimy/bez-procentov/kazan/`, `/zaimy/pod-zalog-pts/sankt-peterburg/`.

Пока структуру не проектировали. К этому типу страницы идем после интента и гео.

Связанные файлы:

- `products/zaimy/structure.md` - логика продукта, URL, масштабирование и ссылки на лендинги.
- `products/zaimy/landings/product/README.md` - согласованная структура продуктовой страницы `/zaimy/`.
- `products/zaimy/research/competitors/slugs.csv` - полный рыночный список найденных слагов.
