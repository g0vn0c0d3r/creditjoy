# Лендинги

Каждый тип публичной страницы лежит в отдельной папке.

- `final.md` - согласованная структура страницы.
- `draft.md` - активный рабочий набросок.
- `planned.md` - тип страницы зафиксирован, но ещё не спроектирован.
- `design/draft.*` - текущий неутверждённый визуальный макет.
- `design/final.*` - утверждённый визуальный макет.

Папку `design/` создаем только вместе с реальным файлом. Рабочие задачи и скриншоты для исправлений храним отдельно в `products/zaimy/changes/`.
