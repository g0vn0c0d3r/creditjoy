# Лендинги

Каждый тип публичной страницы лежит в отдельной папке.

- `README.md` внутри типа лендинга - его основной бриф: роль страницы, состав блоков, данные и порядок их использования.
- `design/draft.*` - текущий неутвержденный дизайн-набросок.
- `design/final.*` - утвержденный макет или дизайн-спецификация.

Папку `design/` создаем только вместе с реальным файлом. Рабочие задачи и скриншоты для исправлений храним отдельно в `products/zaimy/changes/`.
