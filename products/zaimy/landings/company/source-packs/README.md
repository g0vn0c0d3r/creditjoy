# Source packs для МФО

В этой папке хранятся материалы, которые сборщик готовит для последующей загрузки в админку. Для каждой организации создаётся один Markdown-файл с двумя частями:

1. Проверенные данные для полей карточки компании.
2. Сырой контент официального сайта для генерации описаний и FAQ.

## Структура

```text
source-packs/
  README.md
  organizations/
    <organization-slug>.md
```

Файлы организаций находятся в `organizations/`. Один файл относится только к одной организации и её юридическому лицу.

## Правила сбора

Единственный рабочий бриф, схема данных и промпт сборщика находятся в `../draft.md`. README не дублирует эти правила, чтобы между файлами не появлялись расхождения.

Пока бриф не согласован, файлы организаций остаются пустыми и сбор не запускается. После согласования:

1. `draft.md` становится утверждённой спецификацией.
2. По ней создаётся единый шаблон готового source pack.
3. Сборщик заполняет по одному файлу на организацию.
4. Готовый файл отдельно передаётся в AI-окно админки.
