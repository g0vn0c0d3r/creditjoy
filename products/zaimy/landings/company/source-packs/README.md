# Source packs для МФО

В этой папке хранятся проверенные данные, которые сборщик готовит для последующей загрузки в админку. Для каждой организации создаётся один Markdown-файл с таблицами полей карточки компании и использованными официальными источниками. Сырой текст сайтов и документов в source pack не сохраняется.

## Структура

```text
source-packs/
  README.md
  template.md
  organizations/
    <organization-slug>.md
```

Файлы организаций находятся в `organizations/`. Один файл относится только к одной организации и её юридическому лицу.

## Правила сбора

Единственная утверждённая спецификация, схема данных и промпт сборщика находятся в `../final.md`. README не дублирует эти правила, чтобы между файлами не появлялись расхождения.

Рабочий порядок:

1. Сборщик проверяет обязательные источники по `../final.md`.
2. После успешной проверки поэтапно заполняет один файл организации на основе `template.md`.
3. После каждого этапа сохраняет и отправляет изменения в Git.
4. Завершённый файл отдельно передаётся в AI-окно админки.
