# Draft: `/companies/{slug}/`

Статус: рабочий набросок карточки МФО.

## Назначение

Карточка помогает проверить организацию, понять общие условия её займов и разобраться в получении и обслуживании. Это не продуктовый хаб, не витрина именованных офферов и не обзор отзывов.

Этот файл задаёт канонический набор данных для будущих source pack. Точный заполняемый шаблон лежит в `products/zaimy/landings/company/source-packs/template.md`, правила источников — в `products/zaimy/landings/company/source-packs/README.md`.

## Правила данных

1. Названия полей и разделов в шаблоне не меняем: по ним AI сопоставляет данные с полями админки.
2. Для каждого поля передаём одно проверенное значение. Конфликты разрешаем до формирования файла.
3. Если официального значения нет, пишем `Не указано`. Не добавляем пояснения о том, где и почему поле не найдено.
4. Для переключателей используем только `Да`, `Нет` или `Не указано`.
5. Денежные значения указываем в рублях, сроки — в календарных днях, ставки — с единицей измерения.
6. Условия собираем только по действующим потребительским займам самой организации. Рекламу других юридических лиц и каталожные значения не переносим.
7. Краткое и полное описание, FAQ и SEO генерирует AI из официального контента. В блок точных данных их не пишем.
8. Похожие МФО формирует сайт автоматически. В source pack этот блок не передаём.
9. Номер лицензии не собираем и не подменяем номером записи в реестре МФО.

## Инструкция будущему сборщику

1. Получить бренд или URL официального сайта.
2. Установить точное юридическое лицо по официальному сайту и сверить его с Банком России.
3. Проверить реквизиты по официальным документам; ФНС использовать для обязательных отсутствующих полей и разрешения конфликтов.
4. Найти официальные страницы с условиями, требованиями, получением, погашением, продлением, просрочкой и FAQ.
5. Заполнить копию `source-packs/template.md`, не меняя названия разделов и полей.
6. Для отсутствующих значений написать `Не указано`; пустыми оставить только поля, которые админка допускает не передавать.
7. После точных данных добавить буквальный контент официального сайта. Не делать выжимку и не добавлять комментарии между страницами.
8. Проверить, что в файле нет двух значений одного поля, чужих юридических лиц, каталожных данных, отзывов и редакционных догадок.
9. Передать один готовый Markdown-файл в AI-окно админки и проверить результат до применения.

## Критерий готовности source pack

- Все обязательные реквизиты заполнены или явно отмечены как `Не указано`.
- КПП присутствует и проверен.
- Условия имеют единицы измерения и относятся к самой организации.
- В итоговом файле осталась одна версия каждого значения.
- Источники Tier 1 перечислены один раз.
- Сырого официального контента достаточно для краткого и полного описания и 5–9 FAQ.
- Файл содержит только данные и контент, нужные админке.
