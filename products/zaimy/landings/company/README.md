# Лендинг: `/companies/{slug}/`

Статус: в работе.

## Роль страницы

Карточка МФО помогает пользователю проверить компанию и разобраться в её условиях обслуживания. Это не продуктовый хаб `/zaimy/`, не каталог рынка и не редакционный обзор.

На первом этапе не строим витрину именованных офферов. Она появится отдельно, когда будет надёжный источник таких данных.

Правила источников и формат файлов для импорта: `products/zaimy/source-packs/README.md`.

## Каркас страницы

| № | Блок | Состав блока |
| --- | --- | --- |
| 1 | Кратко о сервисе | Бренд, краткое описание, ссылка на официальный сайт. |
| 2 | Условия займов | Диапазоны суммы и срока, ставка, ПСК, льготные условия при наличии. |
| 3 | Получение займа | Формат оформления, требования к заёмщику, документы, идентификация, способы получения денег. |
| 4 | Погашение и обслуживание | Способы погашения, продление, досрочное погашение, просрочка, дополнительные услуги. |
| 5 | Реквизиты и документы | Юрлицо, ИНН/ОГРН/КПП, запись в реестре, адрес, документы, телефон и email. |

| 8 | Источники и дата проверки | Ссылки на официальный сайт, Банк России, документы и дата проверки. |

## 1. Кратко о сервисе

| Данные | Формат значения | Источник данных |
| --- | --- | --- |
| Бренд | Точное публичное название | Официальный сайт компании |
| Краткое описание | Сгенерированный текст | Сырой текст главной и страницы «О компании» с официального сайта |
| Официальный сайт | Полный URL | Официальный сайт компании |
| Статус в реестре | Одно значение: `Действует` / `Исключена` | Банк России |
| Дата проверки | `дд.мм.гггг` | Система: дата последней проверки данных Tier 1 |
