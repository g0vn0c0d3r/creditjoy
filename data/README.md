# Data

## Raw

`raw/wordcraft/` contains the original Wordcraft exports with normalized file names:

- `wordcraft-zaim.xlsx`
- `wordcraft-microzaim.xlsx`
- `wordcraft-microcredit.xlsx`

## Processed

`processed/` is generated by `scripts/build-keyword-map.mjs`.

Important files:

- `summary.md` - quick overview of the processing result.
- `page-candidates.csv` - draft future commercial/support pages with query aliases.
- `page-aliases.json` - complete page-to-query map.
- `all-keywords.csv` - all unique queries, cleaned and assigned to buckets/pages.
- `buckets/brand-keywords.csv` - brand queries.
- `buckets/account-keywords.csv` - personal account/service navigation.
- `buckets/noise-keywords.csv` - technical/domain/Telegram/promo noise.
- `buckets/review-needed.csv` - queries that need manual judgment.
- `buckets/support-keywords.csv` - top/rating/reviews/calculator/refinancing support pages.

## Rule

The source `cluster` column from Wordcraft is ignored. We use the raw query text, deduplicate it, then assign draft intents ourselves.
