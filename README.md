# creditjoy

Рабочий проект для анализа структуры финансовых маркетплейсов и подготовки семантики под будущий сайт.

Первый рабочий продукт - займы. Для MVP держим рядом сервисные блоки: валюты/курсы, конвертеры, блог и карточки компаний. Финальные страницы не утверждаем заранее: сначала чистим семантику и фиксируем только явно коммерческие направления.

## План запуска

1. Собрать конкурентное поле с нуля: базовые займы, займы на карту, ПТС/авто, недвижимость, города.
2. Выбрать SEO-конкурентов: агрегаторы, МФО, региональные сайты, медиа.
3. Разобрать структуру конкурентов: хабы, интенты, гео, карточки, калькуляторы, FAQ.
4. Зафиксировать коротко плюсы, минусы и возможности для CreditJoy.
5. На основе конкурентов собрать карту продукта `займы`: хаб, беззалоговые, залоговые, ПТС/авто, недвижимость, гео.
6. Выбрать MVP-ядро: сильные чистые интенты и ограниченная гео-пачка.
7. Продумать перелинковку: хаб, интенты, города, компании, блог.
8. Снять с конкурентов рабочие структуры страниц и улучшать только там, где есть понятная причина.
9. Определить блоки страниц: офферы, фильтры, калькулятор, ПСК, риски, FAQ, перелинковка.
10. Привязать семантику к готовым слагам; запросы без подходящей страницы отправить в `later` или выкинуть.
11. Собрать первый реестр: `MVP`, `later`, `noindex`, `не делать`, алиасы и канонические страницы.
12. Подготовить данные и контент: компании, условия, города, блог, справочные материалы.
13. Запустить MVP: главная, раздел займов, выбранные интенты, первые гео, компании, блог.
14. Расширять по факту: больше гео, больше интентов, валюты/конвертеры, больше компаний.

## Главные файлы

- `planning/roadmap.md` - общий план запуска и рамка MVP.
- `planning/competitors/top-5.md` - основной список конкурентов для глубокого разбора.
- `planning/competitors/structure-notes.md` - рабочие заметки по структуре конкурентов.
- `planning/product/zaimy.md` - черновик карты продукта `займы`.
- `planning/product/page-structures.md` - структуры страниц на основе конкурентов и правила улучшений.
- `planning/semantics/keyword-processing.md` - как собирается единый файл запросов.
- `planning/semantics/keyword-review.md` - рабочая логика ручного разбора запросов без финальных slug-кластеров.
- `data/raw/wordcraft/` - исходные Excel-файлы Wordcraft.
- `data/keywords.csv` - главный рабочий файл со всеми словами.
- `scripts/build-keywords.mjs` - скрипт, который пересобирает `data/keywords.csv` из исходных Excel-файлов.

## Рабочий файл слов

`data/keywords.csv` - единственный файл, с которым дальше работаем руками.

Поля:

- `query` - запрос.
- `clicks` - клики из Wordcraft.
- `demand` - спрос из Wordcraft.
- `sources` - из каких исходных файлов пришел запрос.
- `decision` - пустое поле для нашего будущего решения.
- `notes` - пустое поле для заметок.

Текущий объем: 5 507 уникальных запросов.

## Текущий принцип

Главный принцип на текущем этапе: один общий файл слов, без преждевременной нарезки на бакеты и страницы.
