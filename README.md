# Market Structure Analysis

Рабочий проект для анализа структуры финансовых маркетплейсов:

- banki.ru
- sravni.ru
- bankiros.ru
- finuslugi.ru
- ru.myfin.by

Цель первой версии: понять, как устроена глубина страниц у крупных игроков, особенно в займах, и собрать основу для нашей SEO/продуктовой стратегии.

## Что внутри

- `docs/01-competitor-structure.md` - карта структуры конкурентов.
- `docs/02-strategy.md` - стартовая стратегия запуска, с фокусом на займы.
- `docs/03-keyword-processing.md` - правила обработки Wordcraft-файлов.
- `data/loan-taxonomy-seed.csv` - черновая матрица страниц для вертикали займов.
- `data/raw/wordcraft/` - исходные Wordcraft `.xlsx`.
- `data/processed/` - обработанные запросы, будущие страницы и алиасы.
- `scripts/build-keyword-map.mjs` - воспроизводимая сборка семантической карты.

## Текущий вывод

Финансовые маркетплейсы строят не одну линейную структуру, а матрицу:

`продукт -> модификатор -> гео -> организация/бренд -> отзывы/рейтинг/калькулятор/контент`

Для старта разумнее не копировать весь масштаб banki/sravni/bankiros, а взять одну вертикаль, где есть экспертиза и монетизация: микрозаймы. Затем аккуратно расширяться в кредиты, карты и страхование.

## Семантика

Текущий обработчик читает 3 Wordcraft-файла: `займ`, `микрозайм`, `микрокредит`. Колонка `cluster` из Wordcraft намеренно игнорируется: будущие коммерческие страницы собираются по нашим правилам и должны пройти ручной пересмотр.

Основные результаты:

- `data/processed/page-candidates.csv` - будущие страницы с алиасами запросов.
- `data/processed/page-aliases.json` - полная карта страниц и запросов.
- `data/processed/all-keywords.csv` - все уникальные запросы с разметкой.
- `data/processed/summary.md` - краткая сводка обработки.
- `data/processed/buckets/` - бренды, личные кабинеты, шум и спорные запросы отдельно.
