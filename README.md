# Market Structure Analysis

Рабочий проект для анализа структуры финансовых маркетплейсов:

- banki.ru
- sravni.ru
- bankiros.ru
- finuslugi.ru
- ru.myfin.by

Цель первой версии: понять, как устроена глубина страниц у крупных игроков, особенно в займах, и собрать основу для нашей SEO/продуктовой стратегии.

## Что внутри

- `docs/01-competitor-structure.md` - карта структуры конкурентов.
- `docs/02-strategy.md` - стартовая стратегия запуска, с фокусом на займы.
- `data/loan-taxonomy-seed.csv` - черновая матрица страниц для вертикали займов.

## Текущий вывод

Финансовые маркетплейсы строят не одну линейную структуру, а матрицу:

`продукт -> модификатор -> гео -> организация/бренд -> отзывы/рейтинг/калькулятор/контент`

Для старта разумнее не копировать весь масштаб banki/sravni/bankiros, а взять одну вертикаль, где есть экспертиза и монетизация: микрозаймы. Затем аккуратно расширяться в кредиты, карты и страхование.
